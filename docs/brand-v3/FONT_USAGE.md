# VDALO typography

## Display
Playfair Display, weights 500-700. Use for H1, H2, selected large numerals and short brand statements.

Fallback for implementation: `Noto Serif Display, Georgia, serif`.

## UI and body
Inter, weights 400-700. Use for navigation, body, forms, tables, UI and captions.

Fallback: `system-ui, sans-serif`.

## Important
Font files are not bundled in this package. Use licensed or properly hosted font sources in the website project.
